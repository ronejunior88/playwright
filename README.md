# ServeRest API Tests

## Projeto

ServeRest API Tests

## Objetivo

Projeto de estudos de automação de testes de API utilizando Playwright + TypeScript.

## API

https://serverest.dev

## Execução

```bash
npm test
```

Ou, para executar apenas o teste de health check:

```bash
npx playwright test tests/health.spec.ts
```

## Relatório

```bash
npm run report
```
